## PARTE 1. DEFINIR EL PROYECTO

### 1. Problema
La problemática principal es la falta de un ecosistema educativo estructurado y alineado con la formación universitaria[cite: 1]. La ausencia de este ecosistema limita el desarrollo del aprendizaje autodidacta y multidisciplinario en los estudiantes[cite: 1].

### 2. Objetivos

* **Objetivo General:**
  Desarrollar una plataforma web centralizada que fomente el aprendizaje autodidacta y multidisciplinario mediante un ecosistema educativo estructurado con videos temáticos y actividades dinámicas[cite: 1].

* **Objetivos Particulares:**
  * **Diseñar** una interfaz de usuario intuitiva que permita contener y visualizar videos cortos enfocados en mantener la atención del espectador[cite: 1].
  * **Construir** la arquitectura técnica del sistema y las bases de datos necesarias para administrar la gestión de usuarios, abarcando los roles de alumnos y profesores[cite: 1].
  * **Elaborar** la lógica de programación para la generación automática de dinámicas o juegos evaluativos que resulten fácilmente configurables por el docente[cite: 1].
  * **Combinar** los distintos componentes web desarrollados para asegurar un despliegue visual limpio que permita el funcionamiento integral del Producto Mínimo Viable[cite: 1].

### 3. Alcance
El proyecto contempla explícitamente:
* Desarrollo del sistema web centralizado e interfaz de usuario intuitiva[cite: 1].
* Gestión y reproducción de videos temáticos[cite: 1].
* Gestión de usuarios con roles de alumnos y profesores[cite: 1].
* Implementación del módulo/IA para transcripción de contenido[cite: 1].
* Lógica de generación automática de dinámicas evaluativas (preguntas, juegos, etc.) configurables por el docente[cite: 1].

### 4. Fuera de Alcance
El proyecto **no** realizará ni abarcará:
* Producción, grabación y creación de contenidos educativos/cursos (labor a cargo de docentes a largo plazo)[cite: 1].
* Esquemas de compensación económica a profesores (gestionados por la institución)[cite: 1].
* Integración directa con la infraestructura tecnológica interna de la universidad[cite: 1].

### 5. MVP (Minimum Viable Product)
Para demostrar la funcionalidad de la propuesta, la versión mínima funcional contendrá:
* Visualización y alojamiento accesible de videos temáticos[cite: 1].
* Módulo de gestión de usuarios (autenticación y roles para profesores y alumnos)[cite: 1].
* Al menos una dinámica evaluativa funcional (soportando ejecución manual si fuera necesario en etapa inicial)[cite: 1].
